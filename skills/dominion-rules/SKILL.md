# Dominion rules

Read `references/rules.md` before answering. It is the shared rules baseline
for every Dominion skill in this repository.

- Card text overrides general rules. When a question hinges on exact card
  wording, quote or ask for the card text rather than reciting it from memory.
- Use current (second-edition / Dominion Online) wording. Say so when an
  answer depends on a first-edition card.
- The Arcana section is provisional. Flag anything you say about Arcana as
  unconfirmed until the rulebook is published.
