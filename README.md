# dominion-playbook

Context and skills that help AI agents understand and play
[Dominion](https://www.riograndegames.com/games/dominion/), with one set of
files shared by Claude Code and OpenAI Codex.

## Contents

| Path | Purpose |
| --- | --- |
| `context/rules.md` | Rules reference for every expansion through Rising Sun (Arcana provisional) |
| `context/strategy.md` | Strategy fundamentals: deck composition, reliability, deck control, payload, archetypes, openings, endgame |
| `context/card-power.md` | Card power levels, their sources and how to read them |
| `context/card-ratings.md` | Community [Card Glicko](https://docs.google.com/spreadsheets/d/1CaVOd1pgAgmjJHXPM1tVMVnlJOLDZaq8BxjW4I1NI1E) ratings, generated by `just refresh-power` |
| `context/combos.md` | Known game-deciding two-card combos and how to counter them |
| `AGENTS.md` / `CLAUDE.md` | Repository instructions that load the context (one file, symlinked) |
| `skills/kingdom-analysis/` | Skill: analyze a kingdom before the game and recommend a plan and opening |
| `skills/play-turn/` | Skill: recommend play order, buys and attack responses for a turn in progress |
| `skills/play-game/` | Skill: play a whole game as one seat through a `dominion` MCP server |
| `evals/kotw/` | Eval set: blind kingdom analyses scored against Reddit Kingdom of the Week threads |
| `protocol/` | `dominion/agent-view@2`: the JSON Schema and spec for the game views, decisions and answers agents play through, with examples |

## How agents load it

- **Context**: `AGENTS.md` requires reading every file in `context/`.
  Claude Code inlines them automatically through `@context/...` imports.
  Codex reads them when following the instruction.
- **Skills**: Codex finds them through `.agents/skills` and Claude Code
  through `.claude/skills`. Both point to `skills/`.
- **Outside this repo**: `packages.default` installs the context, skills and
  protocol under `share/dominion-playbook/`.

## Playing

Agents play through `dominion/agent-view@2` ([`protocol/README.md`](protocol/README.md)):
a JSON view of the game as one seat may know it, its open decision as indexed options,
and an answer of option indices. `dominion-engine`'s `dominion serve` hosts games with
it over MCP; dominion-navigator reads live games on dominion.games.
